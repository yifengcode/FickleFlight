# FickleFlight

## Overview

FickleFlight is a modern, responsive flight and hotel booking web application designed to help users explore destinations and find the best travel deals. Built with React and TypeScript, this application provides an intuitive interface for searching flights, browsing hotel accommodations, and planning your next adventure.

## Key Features

- **Flight Search**: Search for flights with flexible options including one-way and return trips, with support for multiple departure and arrival destinations
- **Hotel Booking**: Browse and search for hotel stays in various destinations worldwide
- **Interactive UI**: Modern, user-friendly interface built with Material-UI components
- **Date Selection**: Integrated date picker for easy travel date selection
- **Destination Exploration**: Discover popular travel destinations and recommended stays
- **Responsive Design**: Optimized for various screen sizes and devices
- **Flight Details**: View comprehensive flight information including duration, airline details, and pricing
- **Search Filters**: Filter and sort results by price, recommendations, and other criteria

## Technology Stack

- **React 19** - Modern UI library for building interactive user interfaces
- **TypeScript** - Type-safe JavaScript for better code quality and developer experience
- **Material-UI (MUI)** - Comprehensive React component library for consistent design
- **React Router** - Client-side routing for seamless navigation
- **Date-fns** - Modern JavaScript date utility library
- **MUI X Date Pickers** - Advanced date/time picker components

## Getting Started

### Prerequisites

Please ensure you have installed <code><a href="https://nodejs.org/en/download/">nodejs</a></code> with a minimum version of 20.

### Installation and Running

To preview and run the project on your device:
1) Open project folder in <a href="https://code.visualstudio.com/download">Visual Studio Code</a>
2) In the terminal, run `npm install`
3) Run `npm start` to view project in browser

The application will open in your default browser at `http://localhost:3000`

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - Ejects from Create React App (one-way operation)
