# FickleFlight

## Overview

FickleFlight is a modern, responsive flight and hotel booking web application that provides users with an intuitive interface to search for flights, explore hotel options, and plan their travels. Built with the latest React and TypeScript technologies, it offers a seamless user experience for all your travel booking needs.

## Key Features

- **Flight Search**: Advanced flight search functionality with autocomplete destination fields and flexible date selection using date pickers
- **Hotel Booking**: Browse and search for hotel accommodations in various destinations with filtering and recommendation options
- **Interactive UI**: Clean and modern user interface built with Material-UI components for a polished look and feel
- **Date Selection**: Integrated date pickers for easy selection of travel dates
- **Navigation**: Intuitive navigation between different sections including Explore, Search, Hotels, and Offers
- **Responsive Design**: Optimized for various screen sizes and devices
- **Search Results**: Comprehensive results page displaying available flights with detailed information
- **Popular Destinations**: Quick access to popular travel destinations like Paris, Greece, Norway, Tuscany, and more

## Technology Stack

- **React 19**: Modern React framework with latest features
- **TypeScript**: Type-safe development
- **Material-UI (MUI)**: Comprehensive component library for UI elements
- **React Router**: Client-side routing for seamless navigation
- **Date-fns**: Modern date utility library
- **Emotion**: CSS-in-JS styling solution

## Getting Started

### Prerequisites

Please ensure you have installed <code><a href="https://nodejs.org/en/download/">nodejs</a></code> with a minimum version of 20.

### Installation & Running

To preview and run the project on your device:
1) Open project folder in <a href="https://code.visualstudio.com/download">Visual Studio Code</a>
2) In the terminal, run `npm install`
3) Run `npm start` to view project in browser

The application will start in development mode and open in your default browser at `http://localhost:3000`.

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - Ejects from Create React App (one-way operation)
