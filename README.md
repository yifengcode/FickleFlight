# FickleFlight

## Description

FickleFlight is a modern flight and hotel booking web application designed to help users search, compare, and explore travel options. Built with a focus on user experience and responsive design, FickleFlight provides an intuitive interface for planning your next adventure.

### What is FickleFlight?

FickleFlight is a comprehensive travel booking platform that streamlines the process of finding flights and hotels. The application features an elegant, user-friendly interface that makes travel planning simple and enjoyable.

### Main Purpose and Functionality

The primary purpose of FickleFlight is to provide users with a seamless travel booking experience. Users can:

- **Search for Flights**: Browse and search for flights with flexible date selection and destination options
- **Explore Hotels**: Discover and compare hotel accommodations across various destinations
- **View Results**: Access detailed search results with comprehensive information about flights and hotels
- **Explore Destinations**: Browse featured travel destinations with beautiful imagery and information

### Key Features

- **Intuitive Search Interface**: Easy-to-use search forms with date pickers and location autocomplete
- **Responsive Design**: Fully responsive layout that works seamlessly across desktop and mobile devices
- **Material-UI Components**: Modern, accessible UI components built with Material-UI
- **React Router Navigation**: Smooth navigation between different sections (Explore, Search, Hotels, Offers)
- **TypeScript Support**: Type-safe development with full TypeScript integration
- **Featured Destinations**: Curated list of popular travel destinations including Paris, Norway, Greece, Switzerland, and more
- **User Account Features**: Profile management and notification system
- **Multiple Airlines Support**: Integration with various airline options (ANA, American Airlines, Turkish Airlines, Singapore Airlines, and more)

### Technology Stack

- **Frontend Framework**: React 19 with TypeScript
- **UI Library**: Material-UI (MUI) v7
- **Routing**: React Router DOM
- **Date Handling**: date-fns with MUI Date Pickers
- **Build Tool**: React Scripts
- **Styling**: CSS Modules

## Getting Started

### Prerequisites

Please ensure you have installed <code><a href="https://nodejs.org/en/download/">Node.js</a></code> with a minimum version of 20.

### Installation and Running

To preview and run the project on your device:

1. Open project folder in <a href="https://code.visualstudio.com/download">Visual Studio Code</a>
2. In the terminal, run `npm install` to install dependencies
3. Run `npm start` to view the project in your browser
4. The application will open at `http://localhost:3000`

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm test` - Launches the test runner
- `npm run build` - Builds the app for production
- `npm run eject` - Ejects from Create React App (one-way operation)
